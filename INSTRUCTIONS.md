## Шаг 1: Настройка Firebase

1. Перейди на [Firebase Console](https://console.firebase.google.com/)
2. Создай новый проект (бесплатный тариф)
3. Включи **Realtime Database**:
   - Нажми "Создать базу данных"
   - Выбери "Начать в тестовом режиме"
   - Нажми "Включить"
4. Включи **Authentication**:
   - Перейди в "Authentication"
   - Нажми "Начать"
   - Включи "Анонимный вход"
5. Получи конфигурацию:
   - Перейди в "Настройки проекта" (шестерёнка)
   - Прокрути до "Ваши приложения"
   - Нажми на </> (веб)
   - Скопируй конфигурацию

## Шаг 2: Настройка конфигурации

Открой `src/firebase/config.js` и замени данные на свои:

```javascript
const firebaseConfig = {
    apiKey: "ТВОЙ_API_KEY",
    authDomain: "ТВОЙ_ПРОЕКТ.firebaseapp.com",
    databaseURL: "https://ТВОЙ_ПРОЕКТ.firebaseio.com",
    projectId: "ТВОЙ_ПРОЕКТ",
    storageBucket: "ТВОЙ_ПРОЕКТ.appspot.com",
    messagingSenderId: "ТВОЙ_SENDER_ID",
    appId: "ТВОЙ_APP_ID"
};
```

## Шаг 3: Настройка Telegram Web App

1. Открой @BotFather в Telegram
2. Создай нового бота: `/newbot`
3. Скопируй токен бота
4. Создай Web App:
   - Отправь `/mybots` -> выбери бота -> "Bot Settings" -> "Menu Button" -> "Configure Menu Button"
   - Отправь ссылку на твой хостинг (см. шаг 4)
   - Выбери название кнопки

## Шаг 4: Хостинг (бесплатно)

### Вариант A: GitHub Pages (рекомендуется)

1. Создай репозиторий на GitHub
2. Загрузи все файлы проекта
3. Перейди в Settings -> Pages
4. Выбери branch "main" и нажми Save
5. Получи ссылку вида: `https://твой-ник.github.io/репозиторий/`

### Вариант B: Firebase Hosting

1. Установи Node.js
2. Выполни в терминале:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase init hosting
   ```
3. Выбери свой проект Firebase
4. Укажи папку проекта: `.`
5. Введи `yes` для SPA
6. Выполни: `firebase deploy`

## Шаг 5: Запуск

1. После деплоя получи ссылку
2. Добавь ссылку в Telegram Bot (см. шаг 3)
3. Открой бота в Telegram
4. Нажми кнопку запуска

## Тестирование без Telegram

1. Открой `index.html` в браузере
2. Или запусти локальный сервер:
   ```bash
   # Python
   python -m http.server 8000
   
   # Node.js
   npx http-server .
   ```
3. Открой `http://localhost:8000`

## Правила игры

### Выжившие (4 игрока)
- Цель: починить 5 генераторов и сбежать
- Управление: джойстик слева, кнопка действия справа
- Взаимодействуйте с генераторами (синие квадраты)

### Убийца (1 игрок)
- Цель: поймать всех выживших
- Быстрее выживших
- Подходи близко к выжившим для поимки

## Возможные проблемы

### Firebase не подключается
- Проверь правильность firebaseConfig
- Проверь правила базы данных в Firebase

### Игра не загружается
- Открой консоль браузера (F12)
- Проверь ошибки в Network вкладке

### Telegram Web App не работает
- Используй HTTPS (обязательно для Telegram)
- Проверь ссылку в BotFather
